# YG以图搜图助手 (YG-ISkit)

Chrome 扩展（MV3，Chrome 116+）：悬停网页图片选引擎直搜，框选截图自动上传 Yandex / Google Lens 识图。配置全本地，无追踪。

## 功能

- 🖱 **悬停直搜** — 鼠标停在图片上浮出引擎图标条，点击即用该图搜索
- 📸 **框选截图识图** — `Alt+Y` 或点工具栏图标，拖拽框选任意区域，松开自动上传
- 🔍 **多引擎** — 内置 Yandex / Google Lens / Bing / Baidu / SauceNAO / Ascii2D / TinEye / Sogou，增删改自由
- ⚙️ **可定制** — 引擎 URL 模板、图标颜色、按钮尺寸与位置、中英界面、明暗主题
- 🧹 **白名单 / 黑名单** — 指定网站启用或禁用悬停搜索
- 📋 **复制截图** — 截图同时写入剪贴板

## 安装

1. 下载或 `git clone` 本仓库
2. 打开 `chrome://extensions/`，开启右上角**开发者模式**
3. 点**加载已解压的扩展程序**，选择本仓库文件夹

## 使用

**悬停搜索**：鼠标停在网页图片上 → 点击图标条里的引擎 → 结果页在新标签打开。开启「同时搜索」后，图标条末尾出现 ∀，一次打开全部启用引擎。

**框选截图**：`Alt+Y` 或点工具栏图标 → 拖拽框选屏幕区域 → 松开自动上传；`Esc` 取消。上传目标默认 Yandex，可在选项页切换 Google 或两者并发。

其余配置（引擎表、快捷键、历史记录、导入导出等）在扩展选项页调整：右键扩展图标 → 选项。
